# 5. KNOWN WARNINGS

Known warning 1:

MODULE_TYPELESS_PACKAGE_JSON warning from:

- lib/calculation-trace/calculationTracePilotMap.js

This warning appears when running:

node scripts\check-calculation-trace-integrity.mjs

Do not add "type": "module" to package.json as part of this migration baseline.

Known warning 2:

Turbopack NFT warning from:

- next.config.ts
- app/api/pnl-import/route.js

This warning may appear during:

npm run build

It is known and unrelated to S03-S12.

Do not treat it as a migration failure unless build behaviour changes.

---

# 6. KNOWN STRUCTURAL NOTES

The current app uses:

- Next.js App Router
- React client components
- localStorage-driven state in existing modules
- output contracts for downstream consumption
- read-only supporting layers for readiness, export, dashboard and quote checking

Some future API work may require separating client-only state from server-safe export structures.

This is deferred until after migration.

---

# 7. DO NOT CLEAN UP BEFORE MIGRATION

Before migration, do not:

- delete legacy routes
- remove Recovery Chain pages
- remove Quote Engine
- refactor source modules
- refactor Calculation Trace
- add "type": "module" to package.json
- convert localStorage state to database state
- add API export endpoint
- add saved quote scenarios
- add PDF quote export
- add AI quote review
- force / to redirect to /business-overview

Migration priority is preserving the current working baseline.

# 8. SAFE POST-MIGRATION CLEANUP OPTIONS

After migration, possible cleanup stages:
