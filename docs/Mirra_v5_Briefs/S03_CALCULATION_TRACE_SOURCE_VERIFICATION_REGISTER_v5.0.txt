# 1. REGISTER PURPOSE

This register records code-level evidence for Calculation Trace source_file population.

source_file must remain null unless the actual implementation source file is verified.

---

# 2. VERIFICATION STATUS LEGEND

- verified: actual source owner found
- partial: strong candidate found, but ownership still needs confirmation
- deferred: source owner not proven yet
- conflict: multiple possible owners found
- not_found: no source evidence found

---

# 3. VERIFICATION CLASSIFICATION LEGEND

- source_owned: file directly calculates or derives the value
- output_contract_passthrough: file returns or passes through the value as an output contract
- selector_shape: file shapes the value for UI/status but does not own it
- storage_shape: file stores a value but does not own its calculation
- deferred: ownership not proven
