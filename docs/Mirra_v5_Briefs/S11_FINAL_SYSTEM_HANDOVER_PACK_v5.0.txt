# 6. SOURCE TRUTH RULES

Locked source truth rules:

- Source modules own their own input and calculation logic.
- Downstream pages must consume output contracts.
- Downstream pages must not read raw inputs directly unless explicitly approved.
- Calculation helpers belong in lib/calculations.
- Selectors must remain pure.
- Hooks may compose output contracts and page state.
- Supporting pages must not rewrite source truth.
- Readiness, export, dashboard and quote checker layers must not patch missing source values.

---
