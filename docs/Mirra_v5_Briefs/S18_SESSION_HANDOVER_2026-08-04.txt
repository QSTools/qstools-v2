5. WORKING CONVENTIONS ESTABLISHED THIS SESSION
--------------------------------------------------------------------

These aren't S18-specific — they apply to any future PowerShell-
delivered code change on this repo, including Rate Builder:

- Every code change delivered as a PowerShell script: full-file
  overwrite (not a patch/regex), automatic timestamped backup before
  writing, BOM-less UTF8 encoding.
- Files only partially viewed are never overwritten wholesale — use
  an anchored find-and-replace instead (with a match-count safety
  check that aborts rather than guesses), or go view the rest of the
  file first.
- Anchored replaces normalise CRLF/LF before comparing, since a pure
  line-ending mismatch caused one real false-abort this session.
- Cross-module joins: prefer a stable, module-owned identity field
  (like asset_id) over a category-style key (like labour's
  staff_type_id) where both exist - the former needs no fallback
  logic, the latter does.
- When a design change is proposed based on the user's stated intent
  but the actual UI reveals a different real need once seen, revert
  cleanly to the last known-good state rather than patching toward
  the new understanding - this session did that once (Section 2,
  6.2's reverted override) and it kept the codebase clean.
