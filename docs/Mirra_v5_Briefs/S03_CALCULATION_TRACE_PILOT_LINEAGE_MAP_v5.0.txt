# 1. PURPOSE

This document defines the first manual lineage pilot for the Calculation Trace supporting module.

The purpose is to prove that a final output number can be traced backward through the system to the raw source values that created it.

This is a manual lineage map only.

It does not calculate values.

It does not change output contracts.

It does not replace owning module formulas.

# 8. PILOT SUCCESS CRITERIA

This pilot is successful only when:

1. Every node has a verified brief_reference.
2. Every non-root node has formula_text copied from the owning brief.
3. Every edge is verified from the owning module formula or output contract.
4. Every branch either reaches a confirmed root input or is clearly marked incomplete.
5. A Required Recovery Per Driver value can be manually re-derived from the trace.
