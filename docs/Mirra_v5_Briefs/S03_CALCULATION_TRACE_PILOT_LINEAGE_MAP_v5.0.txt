# 1. PURPOSE

This document defines the first manual lineage pilot for the Calculation Trace supporting module.

The purpose is to prove that a final output number can be traced backward through the system to the raw source values that created it.

This is a manual lineage map only.

It does not calculate values.

It does not change output contracts.

It does not replace owning module formulas.

---

# 2. PILOT CHAIN

The first verified pilot chain is:

```txt
Business Summary / Required Recovery Per Driver
<- Business Summary / Total Cost Burden
<- Cost Summary / Total Cost Burden
<- Cost Summary / Total People Cost Annual
<- Cost Summary / Total Asset Cost Annual
<- Cost Summary / Total Business Overheads
<- Labour / Total People Cost Annual
<- Assets / Total Asset Cost Annual
<- General Overheads / Total Business Overheads
<- Direct module root inputs; P&L mapped source values remain outside this source-module-level pilot
```

Employee Overheads is not modelled as a separate active module in this pilot unless a later active brief restores that module boundary.

Business Outcome and Business Modelling are excluded from this pilot because they are not yet sufficiently implemented in code.
