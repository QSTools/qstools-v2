# 1. PURPOSE

This document defines the first manual lineage pilot for the Calculation Trace supporting module.

The purpose is to prove that a final output number can be traced backward through the system to the raw source values that created it.

This is a manual lineage map only.

It does not calculate values.

It does not change output contracts.

It does not replace owning module formulas.

---

# 2. PILOT CHAIN

The first verified pilot chain is:

```txt
Business Summary / Required Recovery Per Driver
<- Business Summary / Total Cost Burden
<- Cost Summary / Total Cost Burden
<- Cost Summary / Total People Cost Annual
<- Cost Summary / Total Asset Cost Annual
<- Cost Summary / Total Business Overheads
<- Labour / Total People Cost Annual
<- Assets / Total Asset Cost Annual
<- General Overheads / Total Business Overheads
<- P&L mapped source values / direct module root inputs
```

Employee Overheads is not modelled as a separate active module in this pilot unless a later active brief restores that module boundary.

Business Outcome and Business Modelling are excluded from this pilot because they are not yet sufficiently implemented in code.

# 7. KNOWN GAPS

The following items must be verified before this pilot can be treated as locked:

- Cost Summary parallel formula is not yet represented in this pilot map:
  required_recovery_rate = total_cost_burden / total_productive_output.
  This is a Cost Summary output parallel to Business Summary required_recovery_per_driver, not part of the first Required Recovery Per Driver chain. It must be added to a later Cost Summary coverage pass or explicitly mapped if the pilot scope is expanded.

- Cost Summary compatibility alias is not yet represented in this pilot map:
  total_business_cost_annual = total_cost_burden.
  If this alias exists in code, it must reconcile exactly with total_cost_burden and must be included in a later Cost Summary coverage pass.

- exact Labour root source variables for annual_base_cost and annual_on_costs

- exact Employee Overheads treatment, if any, now that the General Overheads brief says not to recreate a separate Employee Overheads module

- exact Assets root source variables for asset ownership, finance, lease, depreciation/replacement, insurance, registration, other ownership cost, and assigned running cost transfers

- exact General Overheads root source variables for overhead categories, exclusions, adjusted benchmark, and source pool values

- exact Business Summary root driver source for product/unit mode where activity_driver_value = total_derived_units_annual or units_sold_annual

- root P&L mapped source variables for each source module

---
# 8. PILOT SUCCESS CRITERIA

This pilot is successful only when:

1. Every node has a verified brief_reference.
2. Every non-root node has formula_text copied from the owning brief.
3. Every edge is verified from the owning module formula or output contract.
4. Every branch either reaches a confirmed root input or is clearly marked incomplete.
5. A Required Recovery Per Driver value can be manually re-derived from the trace.

---

This pilot map is allowed to be incomplete.
