---
# 7. IMPLEMENTATION RULES

When Calculation Trace is implemented:

- It must not calculate.
- It must not own formulas.
- It must not duplicate source truth.
- It must not infer missing links.
- It must only display verified lineage from documented trace nodes and trace edges.
- Broken or missing lineage must be shown as incomplete, not silently repaired.

---
# 8. FINAL PRINCIPLE

Calculation Trace shows how a number was built. It does not decide what the number is.
