---

# 1. PURPOSE

Quote Checker tests a proposed job or quote against the selected business model.

It answers:

- Does this quote recover enough cost?
- Does this quote align with the selected target model?
- What is the implied labour recovery?
- What is the implied material recovery?
- What margin does the quote appear to produce?
- What part of the quote is creating pressure?
- Is the quote aligned, warning, or not aligned?

Quote Checker does not create source truth.

It tests a proposed quote against the current model.

---

# 3. CORE RULE

Quote Checker must not calculate source business truth.

It may calculate quote-specific test results only.

It must not:

- change Labour
- change Assets
- change General Overheads
- change Cost Summary
- change Revenue Summary
- change Business Summary
- change Business Modelling
- override Model Readiness
- override AI Export trust state
- write back to source modules

It may:

- read the AI-readable Business State Export
- accept temporary quote inputs
- calculate quote-specific test outputs
- compare quote outputs against selected model values
- display alignment, warning, or blocked state
- show quote pressure drivers

# 5. TRUST AND GATING

Quote Checker must respect the current export state.

If AI-readable Business State Export says quote checker use is blocked, Quote Checker must still display but clearly show that the model is not ready to trust.

Quote Checker must expose:

- model trust state
- can_use_for_quote_checker
- blockers
- warnings

Quote Checker must not hide blockers.

---

# 6. CALCULATION BOUNDARY

Quote Checker may calculate only quote-specific values.

Allowed quote calculations:

- total_quote_charge
- total_quote_cost
- gross_profit_dollars
- gross_profit_percent
- implied_labour_charge_rate
- material_markup_dollars
- material_markup_percent
- other_direct_markup_dollars
- other_direct_markup_percent
- labour_recovery_gap
- quote_alignment_status

Quote Checker must not recalculate:

- labour cost rate
- asset cost rate
- overhead burden
- required revenue
- required recovery rate
- business model target values
- source module totals

---

# 7. FIRST ALIGNMENT LOGIC

First pass quote alignment:

- blocked if quote checker permission is false
- blocked if labour hours are zero or negative
- warning if implied labour charge rate is below selected model required recovery
- warning if gross profit percent is below selected model target margin where available
- aligned if no blockers or warnings are present

This is a first commercial test only.

It is not a final estimating system.
