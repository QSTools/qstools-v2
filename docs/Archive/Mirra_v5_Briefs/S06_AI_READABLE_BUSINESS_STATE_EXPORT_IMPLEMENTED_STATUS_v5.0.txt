# 5. TRUST STATE

Implemented trust states:

- trusted
- warning
- blocked

Trust state is derived from:

- S04 Model Readiness
- S05 Business Modelling output contract

Blocked state is used when Model Readiness or Business Modelling is blocked.

Warning state is used when warnings exist but no blockers are present.

Trusted state is used only when no blockers or warnings are present.

# 8. LOCKED BOUNDARIES

AI Export must not:

- calculate Labour
- calculate Assets
- calculate General Overheads
- calculate Cost Summary
- calculate Revenue Summary
- calculate Business Summary
- override Model Readiness
- override Business Modelling
- infer missing source truth
- patch missing values
- call external AI services
- create database persistence in this stage

AI Export may only:

- read existing output contracts
- package the business state
- expose trust state
- expose downstream permission flags
- include blockers and warnings
- display a JSON export preview
