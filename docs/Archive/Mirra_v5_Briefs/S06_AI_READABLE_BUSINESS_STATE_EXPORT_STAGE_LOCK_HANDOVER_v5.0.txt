# 8. LOCKED BOUNDARIES

AI Export must not:

- calculate Labour
- calculate Assets
- calculate General Overheads
- calculate Cost Summary
- calculate Revenue Summary
- calculate Business Summary
- override Model Readiness
- override Business Modelling
- infer missing source truth
- patch missing values
- call external AI services
- create database persistence in this stage

AI Export may only:

- read existing output contracts
- package the business state
- expose trust state
- expose downstream permission flags
- include blockers and warnings
- display a JSON export preview
