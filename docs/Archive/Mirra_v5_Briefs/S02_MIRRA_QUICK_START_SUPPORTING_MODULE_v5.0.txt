## Purpose

Quick Start is a supporting module used to model a fast, simplified job/recovery scenario before the full business model is completed.

It is not part of the core long-form module chain, but source code exposes Quick Start outputs that must be documented so they are not treated as unknown-owner fields.

## Rejected Helper / Display Fields

The following fields are not formal output-contract fields:

- `format_currency`
- `format_hours`
- `format_rate`
- `label`
- `value`

Reason:

These are formatting helpers, generic labels, or display tokens. They must not be treated as business metrics.

## Contract Rule

Quick Start is a supporting scenario layer.

It must not override Cost Summary, Business Summary, Recovery Summary, Labour, Assets, Revenue / COGS, or Cost Allocation outputs.

Downstream modules must not consume Quick Start as a substitute for full model output unless explicitly designed as a quick-start pathway.
