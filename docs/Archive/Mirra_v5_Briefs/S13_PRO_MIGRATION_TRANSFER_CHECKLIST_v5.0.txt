# 9. CURRENT LOCKED ARCHITECTURE RULES

Do not break these rules after migration:

- downstream pages consume output contracts
- source modules own source values
- calculations belong in lib/calculations
- selectors must remain pure
- supporting layers must not patch missing source truth
- readiness gates must not be bypassed
- dashboard must not calculate business values
- quote checker must not become a source module
- AI export must not decide source truth
- navigation must not change the model

# 10. WHAT NOT TO DO DURING MIGRATION

Do not:

- start S14-S19 product expansion
- clean up old routes
- delete Recovery Chain pages
- delete Quote Engine
- refactor Calculation Trace
- refactor source modules
- add API export endpoint
- add saved quote scenarios
- add PDF quote export
- add AI quote review
- force / to redirect
- add "type": "module" to package.json
- change package/config files unless required by install

Migration goal is preservation, not expansion.
