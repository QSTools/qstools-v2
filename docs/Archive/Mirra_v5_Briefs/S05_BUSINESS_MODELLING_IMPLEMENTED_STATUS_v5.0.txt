# 7. LOCKED BOUNDARIES

Business Modelling must not:

- overwrite Labour
- overwrite Assets
- overwrite General Overheads
- overwrite Cost Summary
- overwrite Revenue Summary
- overwrite Business Summary
- override Model Readiness
- infer missing source truth
- patch missing values
- change source module calculations

Business Modelling may only:

- read source output contracts
- read Model Readiness
- store local scenario assumptions
- calculate modelling-only gaps
- expose selected model output
- expose downstream readiness flags
