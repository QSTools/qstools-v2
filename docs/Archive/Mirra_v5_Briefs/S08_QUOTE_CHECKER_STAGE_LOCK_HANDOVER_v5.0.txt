Quote Checker does not hide model blockers or warnings.

---

# 8. LOCKED ALIGNMENT LOGIC

First-pass alignment is locked as:

- blocked if quote checker permission is false
- blocked if labour hours are zero or negative
- blocked if total quote charge is zero or negative
- warning if implied labour charge rate is below selected model required recovery
- warning if gross profit percent is below selected model target margin where available
- aligned if no blockers or warnings are present

This is a first commercial test layer only.

It is not a final estimating system.

---

# 9. LOCKED BOUNDARIES

Quote Checker must not:

- calculate Labour
- calculate Assets
- calculate General Overheads
- calculate Cost Summary
- calculate Revenue Summary
- calculate Business Summary
- change Business Modelling
- override Model Readiness
- override AI Export trust state
- infer missing source truth
- patch missing values
- write back to source modules

Quote Checker may only:

- read the AI-readable Business State Export
- accept temporary quote inputs
- calculate quote-specific test results
- compare quote outputs against selected model values
- display alignment, warning, or blocked state
- display quote pressure drivers
- display model blockers and warnings
