\# Mirra — Chat Upload Requirements Brief



\## WHAT STILL NEEDS TO BE UPLOADED TO A NEW CHAT



STATUS: ACTIVE UPLOAD-GAP BRIEF — MIGRATION CHECKLIST ONLY, NOT A PERMANENT MIRRA SOURCE BRIEF

PURPOSE: List what a new chat session still needs in order to work from verified project state rather than summary/status claims.



CONTEXT:

The repo is the source of truth. A chat session has no direct filesystem access to the repo unless files are uploaded, pasted, or verified by command output.



\---



\# 1. WHY THIS BRIEF EXISTS



A status report describes the repo state.



It is not the repo content.



A chat can only reason from what has actually been uploaded, pasted, or shown in command output.



Claims such as:



\- 262 matched

\- 81 code-only reviewed

\- 0 unknown-owner

\- Model Feedback Loop exists



are useful as reporting, but they are not independently verified by a new chat until the supporting files or audit outputs are provided.
